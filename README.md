# SRT 时间轴修整器

本地运行的字幕时间轴修整 Web 应用。导入 SRT 后，可在可缩放时间轴上直接拖动任意字幕块的起止边界（或整体移动），系统实时保证时间轴合法，并可撤销、导出。

技术栈：Node.js + Express（服务端）+ 原生 HTML/CSS/JS（前端，无任何框架）。

## 一键启动（Docker Compose）

```bash
docker compose up --build
```

启动后在浏览器访问：**http://localhost:3000** （端口 **3000**）

> - 旧版 Docker 请使用 `docker-compose up --build`。
> - 依赖安装与初始化已全部纳入镜像构建与容器启动过程，无需任何额外命令。
> - 如需更换宿主机端口，编辑 `docker-compose.yml` 中 `ports` 的左侧端口（如 `"8080:3000"`），然后访问对应地址即可。

## 本地开发（不使用 Docker）

```bash
npm install
npm start          # 访问 http://localhost:3000 ，可用 PORT 环境变量改端口
npm test           # 运行核心约束引擎单元测试
```

## 功能与规则

- **导入 SRT**：点击「导入 SRT」选择文件，或把 `.srt` 文件拖入页面任意位置；也可点「加载示例」体验。导入时自动规范化：起点不为负、每块 ≥ 500ms、块间 ≥ 100ms（违规块整体后移，保持时长）。
- **可缩放时间轴**：`＋ / －` 按钮、滑块、`Ctrl/⌘ + 滚轮`（以光标为锚点缩放）、「适配」一键显示完整时长；普通滚轮 = 横向滚动。
- **拖动修整**：
  - 拖动字幕块**左/右边缘**调整起点/终点；拖动**块体**整体平移（保持时长）。
  - 实时约束：每块时长 ≥ 500ms、相邻间隔 ≥ 100ms、起点 ≥ 0。
  - 边界越过**后继安全线**（下一块起点前 100ms，拖动时显示为红色虚线）时，超出量会**递归推移**所有受影响的后继块，且每块**时长保持不变**。
  - **向回拖动只释放空隙**，不会把后继块自动拉回。
  - 指针靠近视口边缘时自动横向滚动，长字幕链也能一拖到底。
- **同步显示**：时间轴块与下方列表实时同步显示每块的序号、开始/结束时间码、时长与文本；列表中文本可直接编辑，点击任一行/任一块可联动定位。
- **撤销**：每次拖动自动记录快照，点击「撤销」或按 `Ctrl/⌘ + Z` 可逐级回退（最多 100 步）。
- **导出 SRT**：点击「导出 SRT」下载重新编号、时间码格式标准的合法 SRT 文件（`<原名>.fixed.srt`）。

## 项目结构

```
├── Dockerfile             # 单阶段构建：安装依赖 + 启动服务
├── docker-compose.yml     # 一键启动（端口 3000）
├── package.json
├── server.js              # Express：静态资源 + 健康检查 /api/health
├── public/
│   ├── index.html         # 页面结构
│   ├── style.css          # 深色主题样式
│   ├── engine.js          # 核心约束引擎（解析/规范化/拖动推移，纯逻辑可测）
│   ├── app.js             # 时间轴渲染、拖动交互、缩放、撤销、导入导出
│   └── sample.srt         # 内置示例字幕
└── tests/
    └── engine.test.js     # 引擎单元测试（npm test）
```

## 环境变量

| 变量   | 默认值 | 说明           |
| ------ | ------ | -------------- |
